Taruh foto kegiatan di folder ini. Format nama file:

    <kode-kegiatan>-<nomor>.jpg

Kode kegiatan:
    imac                    -> IMAC (Introduce More About Cisco)
    sharing-session         -> Cisco Networking Sharing Session
    netacad-riders-2026     -> APJC NetAcad Riders Round 1 (2026)
    snc-ix-2026             -> Sumatera Networking Competition (SNC) IX (2026)
    iot-esp32-smkn5         -> Edukasi IoT ESP32 di SMK Negeri 5 Pekanbaru
    hidroponik-zalaponic    -> Edukasi Hidroponik Otomatis di PT Zalaponic

Contoh (satu kegiatan boleh punya banyak foto, urut sesuai nomor):
    imac-1.jpg, imac-2.jpg, imac-3.jpg
    snc-ix-2026-1.jpg, snc-ix-2026-2.jpg

Format yang didukung: jpg, jpeg, png, webp. Pakai huruf kecil.
Saran ukuran: sisi terpanjang sekitar 1600 px dan di bawah 400 KB per foto.
Rasio 4:3 (landscape) paling pas. Foto yang tidak 4:3 dipotong otomatis di tengah.
Kegiatan tanpa foto tetap tampil sebagai teks saja.
